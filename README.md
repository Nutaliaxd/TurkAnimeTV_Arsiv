# TurkAnimeTV_Arsiv
turkanime.tv sitesi kapandı ve kapanmasının ardından arkasında bıraktığı koca arşivi bir şekilde kurtarmaya çalışıyorum.

Şu anlık proje aşırı deneysel ve prototip durumda yani dosyaların karmaşık olması falan bu nedenden ötürü. Elde tutulur bir versiyon çıkınca düzelteceğim.
